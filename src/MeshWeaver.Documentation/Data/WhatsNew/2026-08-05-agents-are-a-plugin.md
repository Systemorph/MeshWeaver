Assistant, Researcher, Worker and the rest of the built-in agents now ship as the **Agent plugin**
— pre-installed, so they are simply there for everyone, exactly as before. Nothing changes in how
you use them.

What changes is how fast they improve: an agent refinement used to ride a full platform release;
as a plugin it reaches every installation within minutes of passing CI, with no restart. On the
MeshWeaver cloud portals these updates apply automatically.

Your own agents are untouched — the Agent space stays yours to add to, and anything you created
there is invisible to plugin updates.
