# Permission changes now take effect immediately

Changing an access assignment — switching someone's role, or denying access to a page — did not
always reach people who already had the page open. The change was saved correctly, but anyone with a
live session could keep seeing the old level of access until they reloaded.

That is fixed. Granting, changing and revoking access now takes effect right away, everywhere.

The same fix removes a delay when access is granted for the first time: a newly shared space or
purchased item now becomes readable as soon as the grant is saved, rather than after a pause.
