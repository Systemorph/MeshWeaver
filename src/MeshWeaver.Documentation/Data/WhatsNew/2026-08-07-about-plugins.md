# The About page now lists every installed plugin

Settings → About has grown into the one page that identifies what your portal is
running: alongside the exact platform version and build commit, it now lists every
installed plugin with its version, module fingerprint, kind and target partition —
live, updating the moment an install lands.

The separate admin-only Plugin Catalog settings page is retired: installing and
updating packages is the Store's job, and the About page is where everyone —
not just admins — can see what is installed.
