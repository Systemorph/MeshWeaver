# New installations arrive with the plugins already installed

Standing up a new installation used to leave one manual step at the end: the plugin catalog was
authorized and populated, but an administrator still had to install each package by hand before the
installation was actually usable.

A new installation now installs the platform plugins itself on first startup — the Store included —
and they track their repository from then on. Combined with self-registration, a new deployment goes
from first boot to a working portal with no manual steps at all.

Installation is deliberately scoped to the sources an operator names. An installation that is also
entitled to purchased content will never auto-install it: that stays an explicit choice.
