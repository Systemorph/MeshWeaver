# Real app icons, and All opens first

App tiles now show each app's own icon instead of a row of identical placeholders — the point of an
icon grid is that you recognise an app before you read its label. Any tile still wearing the generic
placeholder picks up the real icon from the app it opens.

The content list below now opens on **All** — everything you can reach — with **Pinned** as a second
tab when you have pins, and it fills the page rather than showing a handful of items. Things shared
with you appear in that list, grouped by type like everything else, so there is no separate "Shared
with me" section to scroll past.
