# Markdown page rendering restored

After the previous platform update, opening a markdown page could show "This view could not be
rendered" instead of the document. This is fixed: markdown pages render normally again, including
code highlighting, and diagram and math rendering.

If a page still shows the error after your platform has updated, do a hard refresh in the browser
once — the failed script may still be cached.
